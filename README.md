- BIM and i-model workflow examples for collaboration

## Requirements

- Installed MicroStation

## Usage

Open the extracted folder and explore the template and library directories. Import the included `.dgn` templates and cell libraries directly into MicroStation or follow the documentation to configure levels, dimension styles, sheets and plotting. The guides provide practical instructions for each resource.
